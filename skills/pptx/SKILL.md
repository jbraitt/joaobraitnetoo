# Slides PowerPoint

Planeje uma ideia por slide; use proporção 16:9; varie layouts e confira alinhamento, precisão, contrastes e textos antes de entregar. Gere PPTX editável sempre que possível. Este é um guia autoral, não a Skill PPTX proprietária de terceiros.
